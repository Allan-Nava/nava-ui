nava-ui · v0.5.0

A small, dark-first UI kit in plain CSS.

The design tokens and components of allan-nava.github.io, extracted so that other projects can look like they belong together. No build step, no framework, two themes.

Get started Source on GitHub

Get started

One stylesheet, and optionally one script for the theme toggle and the card spotlight.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Allan-Nava/nava-ui@v0.5.0/dist/nava-ui.css">
<script defer src="https://cdn.jsdelivr.net/gh/Allan-Nava/nava-ui@v0.5.0/dist/nava-ui.js"></script>

Then write HTML with the nv- classes shown below. Every example on this page is live, and the source under it is read from the example itself, so the two cannot drift apart.

Form controls

For a form with several fields: nv-field ties a label, a control and a hint together, and nv-input--box gives the input the same corners as the other controls. Checkbox, radio and switch are classes on the native <input>, wrapped in a nv-choice label so the text is part of the target. A switch is a checkbox with role="switch": use it for a setting that applies at once, a checkbox for something sent with the form.

Validation

An invalid control has aria-invalid="true", and its message is linked with aria-describedby: the CSS styles the attribute, so what a screen reader announces and what the eye sees cannot disagree. A valid control has the class is-valid. Neither is told by colour alone: the edge gets thicker and the message has a mark and says what to do.

Alerts

A message in the page, in four tones. The tone is never told by colour alone: each has its own mark and a title that says what happened. Add role="alert" only to a message that appears after an action and needs attention now. A button with data-nv-dismiss removes the alert it is in.

Toasts

A short message over the page that goes away by itself. Call navaUI.toast(message, { tone, title, timeout }): the script creates the live region, so screen readers announce the message, and stops the timer while the pointer or the focus is on the toast. A toast is for something the person can afford to miss; anything they must act on belongs in an alert.

Dialog

The native <dialog>, opened with showModal() or a button with data-nv-dialog="<id>": the browser traps the focus, closes it on Escape, makes the page behind inert and gives the focus back to the button that opened it. The close button sits in a <form method="dialog">, so it works without the script; closedby="any" also closes it on a click outside. Skeleton

Placeholders while content loads, in the shape of what is coming: nv-skeleton sized inline, --line for a line of text, --circle for an avatar. The region carries aria-busy="true" and a "Loading…" for screen readers; the skeletons are aria-hidden. The shimmer stops under prefers-reduced-motion.

Button spinner

A button that is working keeps its label, gets aria-busy="true" and an nv-spinner before the text. It stays readable, unlike a disabled button, and ignores clicks until it is done. The spinner takes the colour of the text and stands still under prefers-reduced-motion.

Pagination

On the first or last page keep the arrow in the markup with aria-disabled="true": it is hidden but still takes its space, so the page number stays centred.

Theming

Dark is the default. Light applies when the system asks for it, and an explicit choice on <html data-theme="light"> or data-theme="dark" wins over both. To remember the choice without a flash on load, put this in <head>, before the stylesheet:

<script>
(function () {
  try {
    var t = localStorage.getItem('nv-theme');
    if (t === 'light' || t === 'dark') document.documentElement.setAttribute('data-theme', t);
  } catch (e) {}
})();
</script>

To make the kit yours, override tokens after the stylesheet. Changing the accent takes six values per theme, because the accent is used both as text and as a background:

:root {
  --nv-accent: #4c8dff;
  --nv-accent-hover: #74a7ff;
  --nv-accent-soft: rgba(76, 141, 255, 0.12);
  --nv-accent-border: rgba(76, 141, 255, 0.35);
  --nv-accent-text: #a9c8ff;  /* text on accent-soft */
  --nv-on-accent: #04101f;    /* text on accent */
}

Check the contrast of each pair you change, in both themes. The full list of tokens and the rules for adding a component are in the README.
