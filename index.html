nava-ui · v0.2.0

A small, dark-first UI kit in plain CSS.

The design tokens and components of allan-nava.github.io, extracted so that other projects can look like they belong together. No build step, no framework, two themes.

Get started Source on GitHub

Get started

One stylesheet, and optionally one script for the theme toggle and the card spotlight.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Allan-Nava/nava-ui@v0.2.0/dist/nava-ui.css">
<script defer src="https://cdn.jsdelivr.net/gh/Allan-Nava/nava-ui@v0.2.0/dist/nava-ui.js"></script>

Then write HTML with the nv- classes shown below. Every example on this page is live, and the source under it is read from the example itself, so the two cannot drift apart.

Form controls

For a form with several fields: nv-field ties a label, a control and a hint together, and nv-input--box gives the input the same corners as the other controls. Checkbox, radio and switch are classes on the native <input>, wrapped in a nv-choice label so the text is part of the target. Theming

Dark is the default. Light applies when the system asks for it, and an explicit choice on <html data-theme="light"> or data-theme="dark" wins over both. To remember the choice without a flash on load, put this in <head>, before the stylesheet:

<script>
(function () {
  try {
    var t = localStorage.getItem('nv-theme');
    if (t === 'light' || t === 'dark') document.documentElement.setAttribute('data-theme', t);
  } catch (e) {}
})();
</script>

To make the kit yours, override tokens after the stylesheet. Changing the accent takes six values per theme, because the accent is used both as text and as a background:

:root {
  --nv-accent: #4c8dff;
  --nv-accent-hover: #74a7ff;
  --nv-accent-soft: rgba(76, 141, 255, 0.12);
  --nv-accent-border: rgba(76, 141, 255, 0.35);
  --nv-accent-text: #a9c8ff;  /* text on accent-soft */
  --nv-on-accent: #04101f;    /* text on accent */
}

Check the contrast of each pair you change, in both themes. The full list of tokens and the rules for adding a component are in the README.
