Integrations

Where Beacon sends what it finds, and what it reads from.

  • SL

    Slack

    Findings as messages in a channel, with a daily digest of what is getting worse.

  • GL

    GitLab

    One issue per finding, closed when the check passes again.

    #alerts
  • PD

    PagerDuty

    Wake someone up only for the checks you mark as urgent.

    #alerts
  • PR

    Prometheus

    Every check as a metric, for the dashboards you already have.

    #metrics
  • GR

    Grafana

    A ready dashboard: uptime, latency and certificate expiry by region.

    #metrics
  • HL

    HLS

    Manifests and segments read the way a player reads them.

    #streams
  • DA

    DASH

    The same checks for MPEG-DASH, period by period.

    #streams

    Webhook

    A JSON body to any URL, signed, for whatever you run yourself.
